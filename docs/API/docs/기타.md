# 관광지 조회 (Tourist Spot)

## 1. 개요

지도 내 범위에 포함된 야영장 등 관광지 데이터를 조회하는 기능입니다.
관광지는 사전 등록된 장소 정보를 기반으로 조회되며, 사용자 사진 데이터와는 별도로 관리됩니다.

---

## 2. 엔드포인트 목록

| 메서드 | URL                     | 설명                |
| --- | ----------------------- | ----------------- |
| GET | `/api/v1/tourist-spots` | 특정 좌표 범위 내 관광지 조회 |

---

## 3. 상세 API 설명

### 3-1. 관광지 범위 조회

* **URL**: `GET /api/v1/tourist-spots`

* **요청 파라미터**:

    * `swLat`: 남서쪽 위도 (필수)
    * `swLng`: 남서쪽 경도 (필수)
    * `neLat`: 북동쪽 위도 (필수)
    * `neLng`: 북동쪽 경도 (필수)
    * `level`: 지도 줌 레벨 (옵션, 필터링에 활용 가능)

* **예시 요청**:

```
GET /api/v1/tourist-spots?swLat=36.5&swLng=123&neLat=37&neLng=130&level=12
```

* **응답 예시**:

```json
[
  {
    "name": "솔향기길야영장",
    "categoryCode": "60506",
    "describe": "야영장",
    "lat": 36.9366307,
    "lng": 126.2912528
  }
]
```

* **필드 설명**:
  \| 필드명       | 타입     | 설명             |
  \|--------------|----------|------------------|
  \| `name`       | string   | 관광지 이름         |
  \| `categoryCode` | string   | 카테고리 코드 (예: 야영장 등) |
  \| `describe`   | string   | 관광지 분류 설명      |
  \| `lat`        | float    | 위도              |
  \| `lng`        | float    | 경도              |
