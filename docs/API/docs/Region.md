# 지역 (Region)

## 1. 개요

**Region**은 사진 등록 시 자동으로 생성/조회되는 행정구역 데이터입니다. 

- Kakao Geo API를 통해 좌표 기반 지역명 매핑을 수행하며, 필요 시 Region 정보를 새로 생성할 수 있습니다.

> 📌 본 API는 외부 사용보다는 **백엔드 내부 동작 이해용**으로 설계되었습니다.

---

## 2. 엔드포인트 목록

| 메서드  | URL                                   | 설명                      |
| ---- | ------------------------------------- | ----------------------- |
| GET  | `/api/v1/regions/geo?lat=...&lng=...` | 위도/경도 기반 지역 정보 조회       |
| GET  | `/api/v1/regions/{id}`                | ID로 지역 정보 조회            |
| POST | `/api/v1/regions`                     | 좌표로 지역 생성 (중복 생성 방지 포함) |

---

## 3. 상세 API 설명

### 3-1. 좌표 기반 지역 검색

* **URL**: `GET /api/v1/regions/geo`

* **요청 파라미터**:

  * `lat`: 위도 (double)
  * `lng`: 경도 (double)

* **응답 예시**:

```json
{
  "province": "서울특별시",
  "district": "강남구",
  "subdistrict": "삼성동"
}
```

* **설명**: Kakao API를 이용해 위/경도 좌표에 해당하는 행정 구역 정보를 반환합니다.
* **참고**:

  * 해당 좌표에 대응하는 Region이 없을 경우 빈 값을 반환할 수 있습니다.

---

### 3-2. ID로 지역 조회

* **URL**: `GET /api/v1/regions/{id}`

* **요청 경로 변수**:

  * `id`: Region 엔티티의 ID 값 (Long)

* **응답 예시**:

```json
{
  "lat": 37.5665,
  "lng": 126.9780,
  "province": "서울특별시",
  "district": "중구",
  "subdistrict": "명동",
  "referenceCount": 5
}
```

* **설명**: 특정 ID에 해당하는 Region의 상세 정보를 반환합니다.
* **참고**:

  * 존재하지 않는 ID인 경우 404 Not Found 발생

---

### 3-3. 좌표로 지역 생성

* **URL**: `POST /api/v1/regions`
* **요청 Body**:

```json
{
  "lat": 34.4962,
  "lng": 126.8536
}
```

* **응답 예시**:

```json
{
  "lat": 34.4962,
  "lng": 126.8536,
  "province": "전라남도",
  "district": "장흥군",
  "subdistrict": "대덕읍",
  "referenceCount": 1
}
```

* **설명**: 좌표에 해당하는 지역이 DB에 없으면 새로 생성하고, 이미 있으면 기존 Region을 반환합니다.
* **참고**:

  * 잘못된 좌표 형식이면 400 Bad Request 발생
  * Kakao API 오류 발생 시 502 또는 커스텀 예외 응답 처리됨

---

## 4. 응답 코드 정리

| 코드  | 설명                 |
| --- | ------------------ |
| 200 | 요청 성공              |
| 201 | 생성 성공              |
| 400 | 잘못된 요청 또는 좌표 형식 오류 |
| 404 | 존재하지 않는 ID 조회 시 발생 |
