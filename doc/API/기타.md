📘 GET /api/v1/tourist-spots
🧭 개요
지도 내 범위에 포함된 관광지(야영장 등)를 조회한다.

🔗 요청
URL : GET /api/v1/tourist-spots

Query Parameters

이름	타입	필수	설명
swLat	float	✅	남서쪽 경계의 위도
swLng	float	✅	남서쪽 경계의 경도
neLat	float	✅	북동쪽 경계의 위도
neLng	float	✅	북동쪽 경계의 경도
level	int	❌	지도 줌 레벨 (옵션, 필터에 사용 가능)

예시 요청

bash
복사
편집
GET /api/v1/tourist-spots?swLat=36.5&swLng=123&neLat=37&neLng=130&level=12
📦 응답
응답 형식 application/json

HTTP 상태코드 200 OK

응답 바디 예시

```json
    [
        {
            "name": "솔향기길야영장",
            "categoryCode": "60506",
            "describe": "야영장",
            "lat": 36.9366307,
            "lng": 126.2912528
        }
    ]
```
🗂 필드 설명
필드명	타입	설명
name	string	관광지 이름
categoryCode	string	카테고리 코드
describe	string	간단한 설명
lat	float	위도
lng	float	경도
