# 지역 (Region)

## 1. 개요

**Region**은 사진 등록 시 자동으로 생성/조회되는 행정구역 데이터입니다.

Kakao geo API를 통해 구현하였으며, 특정 좌표에 대한 지역 정보를 조회하거나 등록하는 API가 존재합니다.

문서화는 했지만, **외부 사용 목적이 아니라** **"백엔드 내부 동작 이해용"** 으로 남깁니다.

## 2. 엔드포인트 목록

| 메서드 | URL | 설명 |
| --- | --- | --- |
| GET | `/api/regions/geo?lat=...&lng=...` | 좌표(lat, lng) 기반 지역 정보 조회 |
| GET | `/api/regions?id=...` | ID로 지역 조회 |
| POST | `/api/regions` | 좌표로 지역 생성 (필요 시) |

## 3. 상세 API 설명

### 3-1. 좌표 기반 지역 검색

- **URL**: `GET /api/regions/geo`
- **요청 파라미터**:
    - `lat`: 위도 (double)
    - `lng`: 경도 (double)
- **응답 예시**:

    ```json
    {
      "province": "서울특별시",
      "district": "강남구",
      "subdistrict": "삼성동"
    }
    ```

- 참고
    - 해당 좌표에 대응하는 행정구역을 조회합니다.
    - 없으면 빈 값이 반환될 수 있습니다.

---

### 3-2. ID로 지역 조회

- **URL**: `GET /api/regions?id={id}`
- **요청 파라미터**:
    - `id`: 지역 ID (Long)
- **응답 예시**:

    ```json
    {
      "id": 1,
      "province": "서울특별시",
      "district": "강남구",
      "subdistrict": "삼성동",
      "createdAt": "2025-04-26T15:00:00"
    }
    ```

- 참고:
    - 존재하지 않는 ID 조회 시 404 응답

---

### 3-3. 좌표로 지역 생성

- **URL**: `POST /api/regions`
- **요청 Body**:

    ```json
    {
      "lat": "37.5665",
      "lng": "126.9780"
    }
    ```

- **응답 예시**:

    ```
    {
        "id": 1,
        "lat": 34.496237122,
        "lng": 126.853697779,
        "province": "전라남도",
        "district": "장흥군",
        "subdistrict": "대덕읍",
        "referenceCount": 1
    }
    ```

- **주의사항**:
    - 잘못된 좌표 형식 입력 시 400 Bad Request
    - 이미 존재하는 지역이면 중복 생성하지 않고 기존 지역 반환

---

## 4. 응답 코드 정리

| 코드 | 설명 |
| --- | --- |
| 200 | 요청 성공 |
| 201 | 생성 성공 |
| 400 | 좌표 형식 오류 |
| 404 | 해당 지역 ID 없음 |
